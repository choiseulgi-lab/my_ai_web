## 컬러 사용 가이드

### Primary (`#DCED1E`)
- CTA 버튼 배경, 네비게이션 로고 강조에 사용
- 다크 배경(`#1A1A2E`) 위에서 최대 효과 발휘
- 섹션 구분선·밑줄 장식선에 포인트로 활용
- 텍스트 위에 올 때는 반드시 다크 계열 글자색(`#1A1A2E`) 사용

### Secondary (`#1A1A2E`)
- 내비게이션 바, 히어로 섹션, 푸터(Contact) 배경
- 강한 대비가 필요한 텍스트 블록
- 화이트·옐로우와 조합하여 볼드한 인상 형성

### Accent (`#2D45D4`)
- 섹션 레이블(캡션) 텍스트 강조
- 링크 기본 색상 및 도형 포인트
- 옐로우와 함께 쓰지 않고 단독 포인트로 사용

### Off-white (`#F5F5EC`)
- 페이지 전체 배경으로 일관되게 유지
- 순백(`#FFFFFF`)보다 눈의 피로도가 낮고 콘텐츠 집중도 향상

### Charcoal (`#2D2D2D`)
- 본문 텍스트 전반
- `#1A1A2E`보다 부드러운 인상이 필요한 영역에 사용

## 컴포넌트별 적용 예시

### 버튼
```css
.btn-primary {
  background-color: var(--color-button-primary);  /* #DCED1E */
  color: var(--color-secondary);                  /* #1A1A2E */
  font-weight: 700;
  border: none;
}
.btn-primary:hover {
  background-color: var(--color-button-hover);    /* #C8D818 */
}

.btn-outline {
  background-color: transparent;
  border: 1.5px solid var(--color-secondary);     /* #1A1A2E */
  color: var(--color-secondary);                  /* #1A1A2E */
}
.btn-outline:hover {
  background-color: var(--color-secondary);
  color: var(--color-button-primary);             /* #DCED1E */
}
```

### 카드
```css
.card {
  background-color: var(--color-bg-secondary);    /* #FFFFFF */
  border: 1px solid var(--color-border);          /* #DEDED4 */
  color: var(--color-text-primary);               /* #1A1A2E */
}
.card:hover {
  border-color: var(--color-button-primary);      /* #DCED1E */
  box-shadow: 0 2px 12px rgba(220, 237, 30, 0.2);
}
```

### 다크 섹션 (히어로, 헤더, Contact)
```css
.section-dark {
  background-color: var(--color-bg-dark);         /* #1A1A2E */
  color: #FFFFFF;
}
.section-dark .label {
  color: var(--color-button-primary);             /* #DCED1E */
}
```

## 반응형 고려사항

### 모바일 (xs ~ sm: 0px ~ 599px)
- 배경색 `#F5F5EC` 동일하게 유지
- 다크 헤더(`#1A1A2E`) 영역 높이 축소
- 버튼은 `width: 100%` 풀 너비로 확장
- 옐로우(`#DCED1E`) 강조 요소 크기 비례 축소

### 태블릿 (md: 900px ~ 1199px)
- 라이트 섹션(`#F5F5EC`, `#FFFFFF`)과 다크 섹션(`#1A1A2E`)을 번갈아 배치해 리듬감 형성
- 카드 배경 `#FFFFFF`로 오프화이트 배경과 구분감 유지

### 데스크탑 (lg: 1200px~)
- 히어로 섹션 다크 배경(`#1A1A2E`)을 풀 스크린으로 활용
- 옐로우(`#DCED1E`) CTA 버튼을 중앙에 배치해 시선 집중
- 일렉트릭 블루(`#2D45D4`)는 섹션 레이블에 사용해 전체 흐름 안내

### 다크모드 대응 (선택)
```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary: #1A1A2E;
    --color-bg-secondary: #22223A;
    --color-text-primary: #F5F5EC;
    --color-text-secondary: #DEDED4;
    --color-border: #2A2A3E;
  }
}
```
